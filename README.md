# ParserReview Bot — Парсер отзывов Wildberries

Telegram-бот для парсинга отзывов и вопросов с товарных страниц Wildberries. Получает данные, анализирует тональность и отдаёт пользователю готовый Excel-файл с графиками и статистикой.

---

## Что умеет бот

- Принимает ссылку на товар Wildberries
- Запускает headless-браузер (Playwright), перехватывает ответы WB API
- Извлекает **отзывы** (текст, оценка, дата, плюсы/минусы) и **вопросы с ответами**
- Анализирует тональность отзывов на русском языке (словарный метод + рейтинг)
- Генерирует Excel-файл с цветовой разметкой, сводной таблицей и двумя диаграммами
- Показывает прогресс в реальном времени в Telegram
- Ограничивает частоту запросов (rate limit per user)
- Проверяет подписку на канал перед обработкой

## Технологии

| Слой | Инструменты |
|------|-------------|
| Telegram-бот | aiogram 3.4.1 (async) |
| Парсер | Playwright 1.57.0 (headless Chromium) |

| Деплой | Docker, Railway.app |

## Переменные окружения

| Переменная | Обязательная | По умолчанию | Описание |
|-----------|-------------|-------------|---------|
| `BOT_TOKEN` | Да | — | Токен Telegram-бота |
| `ADMIN_IDS` | Нет | `[]` | ID администраторов через запятую |
| `REQUIRED_CHANNEL` | Нет | `@khosnullin_channel` | Канал, на который нужна подписка |
| `RATE_LIMIT_REQUESTS` | Нет | `5` | Макс. запросов на пользователя |
| `RATE_LIMIT_HOURS` | Нет | `1` | Период ограничения (часы) |
| `MAX_REVIEWS` | Нет | `1000` | Лимит отзывов |
| `MAX_QUESTIONS` | Нет | `1000` | Лимит вопросов |
| `PARSER_TIMEOUT` | Нет | `60000` | Таймаут Playwright (мс) |
| `PARSER_HEADLESS` | Нет | `True` | Запуск браузера без UI |
| `RETRY_MAX_ATTEMPTS` | Нет | `3` | Кол-во попыток при ошибке |
| `SUPABASE_URL` | Условно | `""` | URL для Supabase (если облачный режим) |
| `SUPABASE_KEY` | Условно | `""` | Ключ Supabase |

## База данных

Три таблицы (одинаковый интерфейс для SQLite и Supabase):

- **users** — Telegram ID, имя, дата первого/последнего обращения, счётчик запросов
- **requests** — история запросов: маркетплейс, URL, кол-во отзывов, успех/ошибка
- **rate_limits** — временны́е метки запросов для контроля лимитов

Переключение между SQLite и Supabase — через наличие `SUPABASE_URL` / `SUPABASE_KEY` в `.env`.

## Excel-файл

**Лист «Отзывы»:**
- Столбцы: Автор, Рейтинг, Дата, Текст, Плюсы, Минусы, Тональность
- Цветовая разметка строк: зелёный / красный / жёлтый

**Лист «Анализ»:**
- Распределение тональности (кол-во + %)
- Средний рейтинг
- Топ-10 ключевых слов
- Кол-во проблемных отзывов
- Круговая и столбчатая диаграммы

## Ограничения

- Playwright требует ~500 МБ RAM на контейнер
- Структура WB API может меняться (есть DOM-fallback)
- Ozon в URL-валидаторе поддержан, парсер для него не реализован
- SQLite не сохраняется при рестарте на Railway — нужен Supabase
